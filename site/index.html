Mujina on the BZM2 RDS control board

Bringing up the Mujina mining daemon on Intel Blockscale BZM2 hardware, starting with the RDS 2.0 control board. This site publishes the validation test matrix and its live results.

Test matrix and live results →

What is published here

Case identity, objectives, procedures and pass criteria, and per-run status and timings. Measurements, temperatures, serial numbers, host names and paths are deliberately not published, and a check refuses the deploy if any appear.

See the repository and its publication rules.
